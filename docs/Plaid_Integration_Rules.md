# Правила интеграции Plaid (Ophir)

## Архитектура

* Реализовывать Plaid как полностью отдельный модуль.
* Весь код, относящийся к Plaid, должен находиться только в собственных файлах.
* **Не** изменять существующий код Manual.
* Если Plaid требуется использовать модели, сервисы или другую логику Manual, делать это только через импорты и существующие публичные интерфейсы.

## Общая инфраструктура

* По возможности использовать существующую централизованную архитектуру **Theme V1 (Core)**.
* Не дублировать общие модели, сервисы, утилиты или инфраструктуру, если они уже существуют в Core.

## Процесс работы

* **Не** запускать `test`, `analyze`, `build`, `flutter test`, `dart analyze` и любые другие проверки.
* Все тесты, анализ, сборку и другие проверки проекта запускаю я самостоятельно.
* Работать строго по текущему этапу.
* Не переходить к следующему этапу без моего явного подтверждения.
